# Монитор сетевого трафика для Windows 11 на Python

Программа показывает входящий и исходящий трафик отдельно для каждого активного сетевого интерфейса: скорость и объём за текущий запуск. Читает системные счётчики через `psutil`, без захвата пакетов и вызовов PowerShell.

## Установка

Нужен **Python 3.10 или новее** и пакет `psutil` версии 7.x. Откройте терминал в каталоге проекта:

```cmd
py -3 -m venv .venv
.venv\Scripts\python.exe -m pip install -r requirements.txt
```

Если команды `py` нет, используйте `python` вместо `py -3`. Python можно установить с [официального сайта](https://www.python.org/downloads/windows/). Программа и запускатель сами ничего не устанавливают и не меняют настройки системы. Обычно административные права для чтения счётчиков не нужны.

## Отдельное окно и меню

Дважды щёлкните **`Start-TrafficMonitor.cmd`**. Откроется новое окно Windows Terminal; при его отсутствии — обычное консольное окно. Запускатель использует Python из `.venv`, если он есть; иначе проверяет `py -3`, затем `python`. При отсутствии Python или зависимости показывает инструкции. Для меню в текущем терминале:

```cmd
.venv\Scripts\python.exe -X utf8 traffic_monitor.py --interactive
```

Русское меню позволяет начать мониторинг, выбрать адаптеры по номерам, изменить интервал, включить/выключить CSV, открыть справку и выйти. Настройки сохраняются до закрытия программы. Каждый старт обнуляет итоги. Для повторной записи CSV выберите новое имя файла.

Панель обновляется на месте. Отдельно показаны **ВХОДЯЩИЙ**, **ИСХОДЯЩИЙ** и объём за текущий запуск; единицы автоматически меняются от Б до КиБ, МиБ, ГиБ и ТиБ. **Q** (латинская) или **Esc** возвращает в меню, в том числе во время ожидания следующего измерения. Ctrl+C во время мониторинга тоже возвращает в меню, в главном меню — завершает программу. Для отображения всех адаптеров увеличьте окно: длинные строки и нижняя часть панели ограничиваются его размером. Меню требует обычную консоль без перенаправления ввода/вывода.

## Командная строка

CLI работает без меню; Ctrl+C останавливает наблюдение. В примерах `py -3` можно заменить на `.venv\Scripts\python.exe`:

```cmd
REM Все активные интерфейсы
py -3 -X utf8 traffic_monitor.py

REM Один адаптер; имена задаются точно, без шаблонов
py -3 -X utf8 traffic_monitor.py --adapter "Ethernet"

REM Несколько адаптеров, интервал две секунды
py -3 -X utf8 traffic_monitor.py --adapter "Ethernet" --adapter "Wi-Fi" --interval 2

REM Десять измерений, новый CSV
py -3 -X utf8 traffic_monitor.py --samples 10 --csv traffic-example.csv

REM Справка по параметрам
py -3 -X utf8 traffic_monitor.py --help
```

`--samples 0` (по умолчанию) — без ограничения. Интервал: от 0.1 до 3600 секунд; принимается точка или запятая. Первое измерение выводится после первого интервала; начальные значения счётчиков служат точкой отсчёта. В CLI записи выводятся последовательно, что удобно для перенаправления вывода; обновление панели на месте используется в меню. Для просмотра имён интерфейсов откройте пункт выбора адаптеров.

## Счётчики и CSV

Скорость — изменение счётчика, делённое на фактическое время между чтениями, а не только заданный интервал. 1 КиБ = 1024 байта, 1 МиБ = 1048576 байт. Если счётчик уменьшился, прирост этого направления за интервал принимается равным нулю; накопленные итоги сохраняются, на панели показан сброс.

Отключённый интерфейс временно исчезает из вывода. После возвращения первое чтение устанавливает новую точку отсчёта, сохраняя итоги. Трафик во время отсутствия и сброса нельзя точно восстановить. Новые активные интерфейсы добавляются автоматически в режиме всех адаптеров. Если активных интерфейсов нет, программа продолжает ждать.

CSV создаётся при первом измерении активного интерфейса, в UTF-8 с BOM. Если активных измерений не было, файл не создаётся. Укажите существующий каталог и новое имя: существующий файл не перезаписывается. Каждая строка содержит время ISO 8601 с часовым поясом, имя, скорости в **байтах/с**, объёмы и приросты в **байтах**, признак сброса `CounterReset`. Названия столбцов сохранены: `Timestamp`, `AdapterName`, `ReceivedBytesPerSecond`, `SentBytesPerSecond`, `SessionReceivedBytes`, `SessionSentBytes`, `ReceivedDeltaBytes`, `SentDeltaBytes`, `CounterReset`.

## Ограничения

Это трафик интерфейсов, а не отдельных процессов или сайтов. Он включает локальную сеть и фоновые подключения; это не отдельный счётчик интернет-трафика. Все активные интерфейсы включают виртуальные и loopback, если Windows предоставляет их счётчики. Драйверы могут учитывать байты по-разному. Один поток может проходить через несколько интерфейсов, поэтому суммирование всех строк может посчитать его несколько раз. Очень короткие интервалы увеличивают накладные расходы. Состояние не сохраняется между запусками.

## Проверка

Детерминированные тесты используют стандартный `unittest`, имитацию счётчиков, клавиш, времени и меню; сетевые подключения и `psutil` для них не нужны:

```cmd
py -3 -X utf8 -m unittest discover -s tests -v
```

Тесты проверяют фактические интервалы, независимые итоги, большие целые счётчики, сброс/отключение/возвращение, выбор активных интерфейсов, CSV, формат и границы панели, настройки/ошибки/справку меню, Q/Esc и прерывание ожидания. Проверка на реальной Windows:

```cmd
py -3 -X utf8 traffic_monitor.py --interval 0.5 --samples 2 --csv traffic-smoke.csv
```

Внешний вид нового окна, клавиатуру и изменение размера окна следует проверить вручную. Программа совместима с Python 3.10+, но фактически проверенная версия указана в отчёте разработки.
