# Монитор сетевого трафика для Windows 11

PowerShell-скрипт показывает входящий и исходящий трафик отдельно для каждого активного сетевого адаптера: скорость в КиБ/с и объём за текущий запуск в МиБ. Использует системные счётчики `Get-NetAdapterStatistics`, без установки зависимостей и захвата пакетов. Совместим с Windows PowerShell 5.1.

## Запуск

Откройте PowerShell в каталоге проекта:

```powershell
# Все адаптеры со статусом Up, включая виртуальные
.\scripts\Watch-NetworkTraffic.ps1

# Узнать имена адаптеров
Get-NetAdapter | Format-Table Name, Status

# Один адаптер или несколько; имена задаются точно, без шаблонов
.\scripts\Watch-NetworkTraffic.ps1 -AdapterName 'Wi-Fi'
.\scripts\Watch-NetworkTraffic.ps1 -AdapterName 'Ethernet', 'Wi-Fi' -IntervalSeconds 2

# Десять измерений с записью в новый CSV-файл
.\scripts\Watch-NetworkTraffic.ps1 -SampleCount 10 -CsvPath .\traffic.csv
```

Для остановки нажмите **Ctrl+C**. Параметр `SampleCount` по умолчанию равен `0` — наблюдение без ограничения. Допустимый интервал: от `0.1` до `3600` секунд. Первое измерение выводится после первого интервала; начальные значения счётчиков служат только точкой отсчёта.

Если локальная политика разрешает, но блокирует скачанный файл, снимите метку скачивания:

```powershell
Unblock-File .\scripts\Watch-NetworkTraffic.ps1
Unblock-File .\scripts\TrafficMeasurement.psm1
```

Если выполнение скриптов запрещено вашей политикой, используйте разрешённый в вашей среде способ запуска. Скрипт сам не меняет политику выполнения. Обычно административные права для чтения счётчиков не нужны; доступ может зависеть от настроек Windows.

## Как читать результат

- `In KiB/s`, `Out KiB/s`: изменение счётчиков, делённое на фактическое время между чтениями, а не только заданный интервал. 1 КиБ = 1024 байта.
- `In MiB`, `Out MiB`: накопленный объём с начала наблюдения. 1 МиБ = 1048576 байт.
- `CounterReset`: уменьшился хотя бы один счётчик. Для уменьшившегося счётчика этот интервал даёт нулевой прирост; накопленные итоги сохраняются.

При отключении адаптер временно исчезает из вывода. После возвращения первая запись устанавливает новую точку отсчёта, сохраняя итоги. Трафик во время отсутствия и интервала сброса нельзя точно восстановить. В режиме всех активных адаптеров вновь появившиеся адаптеры добавляются автоматически. Если активных адаптеров нет, скрипт продолжает ждать и сообщает об этом.

CSV содержит одну строку на адаптер и измерение: время в ISO 8601 с часовым поясом, имя, скорости в **байтах/с**, накопленные объёмы и приросты в **байтах**, признак сброса. CSV создаётся при первом измерении активного адаптера; если таких измерений не было, файл не создаётся. Укажите существующий каталог и новое имя файла: существующий файл скрипт не перезаписывает. Для чтения:

```powershell
Import-Csv .\traffic.csv | Format-Table
```

## Ограничения

Это счётчики сетевых интерфейсов, а не отдельных процессов или сайтов. Они включают локальную сеть и фоновые подключения; это не отдельный счётчик интернет-трафика. Драйверы и виртуальные интерфейсы могут учитывать байты по-разному. Один поток может проходить через несколько интерфейсов, поэтому суммирование всех строк может посчитать его несколько раз. Очень короткие интервалы увеличивают накладные расходы. Одного запуска достаточно для наблюдения; состояние не сохраняется между запусками.

## Проверка

Детерминированные тесты не требуют сетевых подключений или сторонних модулей:

```powershell
.\tests\Test-TrafficMeasurement.ps1
```

Они проверяют фактические интервалы, независимые итоги адаптеров, сброс одного счётчика, отключение и повторное подключение, точность больших счётчиков. Проверка на реальной Windows:

```powershell
.\scripts\Watch-NetworkTraffic.ps1 -IntervalSeconds 0.5 -SampleCount 2 -CsvPath .\smoke.csv
Import-Csv .\smoke.csv | Format-Table
```
